# Blood Bowl 六维球探

六维球探及统一入口的公开源码。这里的网页内容与已公开发布的网站一致，压缩脚本已无损还原为可读 JavaScript。

- [六维球探](https://blood-bowl-six-axis-scout.dd-bb1.chatgpt.site/)
- [游戏源码](https://github.com/YDD060404/Bloodboard-public)
- [在线游戏](https://bloodboard-match.onrender.com/)

## 本地运行

```sh
python3 -m http.server 8874 --directory web
```

打开 http://localhost:8874/ 。入口源码在 `portal/`。
