HOW TO READ

六边形怎么看

当前约定的六维是 快攻、控球、杀伤、生存、控场、适应力。适应力拆成个人角色覆盖，以及放进指定阵容后的队内贡献；队内重要性通过移除球员、允许替补接任/重新分工，再与普通同位置球员替换作差。可靠性仍是每项任务都要检查的成功条件和风险记录，不再单列为第六维。

展开旧版代理公式、固定条件与局限

排名赋分与重掷

同组 N 个对象按原始分降序。并列名次用占据名次的平均数 r̄：P=100×(N−r̄)/(N−1)；只有一个对象时记 100。自然 1 失败、自然 6 成功；普通重掷 p′=p+(1−p)p，Pro 为 p′=p+(1−p)(4/6)p。移动路径逐步追踪 Dodge、Sure Feet、Pro 是否已消耗，只能重掷当前失败项。

旧版任务与独立情境项

  1. 快攻：已持球球员的全程可达距离曲线。每格分别计算开阔路线与经过一名标记者的路线，逐步计入闪避、飞跃、冲刺、重掷和行动可用率；并将最长合法移动距离纳入。快攻=100×[0.70×两种路线的平均期望可达距离÷12+0.30×两种路线的平均可用最大距离÷12]。6、8、10 格的站立抵达率仍单独展示；超出最大距离的任务仍记 0，但不会令整条快攻轴归零。No Ball 为 0。
  2. 控球：取得=mean(空路拾球概率×抵达率, 受标记拾球概率×抵达率)；保留=mean(普通阻挡后持球, Strip Ball 后持球)；转移=mean(受标记接球, Quick Pass×行动可用率×AG3+ 队友接球)；控球=100×mean(取得,保留,转移)。内部概率统一保持 0–1，最后才换算成 0–100；三组等权是暂定项目指数，原始列仍分开显示。No Ball 为 0。
  3. 杀伤：固定站立目标 ST3/AV9，阻挡骰按双方 ST 决定骰数与选骰方；宣告普通 Block 时，Brawler 可策略性重掷一个 Both Down。阻挡路线指数为 75% × 安全击倒率 + 25% × 安全移出率：安全击倒是主要、可重复的战斗结果；安全移出是更重的后果，且属于击倒子集，所以只作严重度加权，不重复视为独立事件。特殊攻击和已满足条件的犯规分别按其移出率作为替代路线，取可用路线最高值；球队再按杀伤序位使用指数权重，显出多名强力攻击手的阵容深度。各原始击倒、破甲、移出和 turnover 概率仍分列；棋盘位置、整队支援与完整犯规行动链尚未模拟。
  4. 生存：分别面对 ST3、4、5、6 的无支援阻挡者，四种力量基准等权；每种情境依次计算站立、当前留场、下一进攻段可用，再将三项等权合成 生存指数=100×mean(ST基准下的三项结果)。因此高 ST 会直接改变对方阻挡骰数与被推倒概率，力量高即使不移动也有生存收益。倒地与 Wrestle、护甲、伤害表、厚头骨、衰朽和重生分支分别计算。重生只改善之后回场，不增加当前留场率；KO 后续回场按一次 4+ 检定估计。无支援、无边线、无队医是固定情境代理，不是整场生存率。另有独立的 v3 原始任务观察：受击后下次激活能否移动到指定格并以站立状态结束，由 Bloodboard 解析起身、Jump Up、Pick-me-up、移动和 Turnover；目前不并入此旧版生存指数，也不代表球员所有职责的完整执行概率。
  5. 控场：固定对手 AG3+、Dodge、一个标记者；先算牵制、本人阻挡威胁、特殊控制和 Guard 支援，再拆为静态与动态两项。静态守区 =100×mean(固定压制指数, 对手 ST3/4/5/6 阻挡后仍站立率)；动态延伸 =100×固定压制指数×可达距离比例；总控场指数 =min(100, 静态守区+动态延伸)。移动只增加可覆盖范围，不会抹掉低速球员原地已有的控制。Guard 情境是假定 ST3 支援球员被标记：无 Guard 时队友无法助攻；有 Guard 时允许助攻，使 ST3/Block 对 ST3 从一骰变为两骰，支援值是两种情况下安全击倒率的差。ST3/4/5/6 无支援力量基准仍是局部代理，不是整张棋盘路线搜索。力量会改变阻挡骰选择权和击倒风险，但不会抵消已选的 Push；Stand Firm/Rooted 和实际推挤格选择决定位移。总控场是封顶的暂定比较指数，不是概率。
  6. 适应力：个人角色覆盖与队内贡献（历史代理构成，暂未标定）：五种职责（持球推进、得分接应、稳定突袭、封路保护、开路支援）逐项列出任务值 Rᵣ 和单角色阈值覆盖度 Cᵣ=100×clamp((Rᵣ−Lᵣ)/(Hᵣ−Lᵣ),0,1)。前四种角色的 L/H=35/75；开路支援用 Guard 对标准阻挡击倒率的边际百分点、阈值 2/14。目前只展示职责向量，不据这些阈值生成正式个人适应力分。队内贡献须对指定阵容计算完整阵容、移除该球员并允许替补/重新分工、同位置普通球员替换的差值。

球队实验总评（接入个人任务画像）

球队排名只纳入 V7.0.1 校验通过的构筑。快攻、控球、杀伤、生存、控场五维分别从同赛制 V7.0.1 球员候选画像中选最佳 11/7 人，按 e^(−0.38×序位) 加权汇总；缺少 V7 任务数据的球员轴族回退到有标记的 V410 代理。适应力按全队职责任务及缺员后重分工保留率计算。阵容购买技能及当前规则造成的属性差异，用旧规则公式与基础位置档案的个人边际差暂定修正。生存与控场基础分分别取球员阵容任务点、整队留场/控区任务同赛制排名点的均值；再单独比较当前力量阵容与同名单全 ST3 反事实，把盯防格增量、受击站立率增量、留场率增量分别赋予赛制内名次点，合成后每高于中位 1 点加 0.5 分，单轴最多加 25 分，低于中位不扣分。该项直接体现力量对保住区域和抵御冲击的整队贡献。球队总赋分按快攻22%、控球18%、杀伤16%、生存15%、控场15%、适应力14%加权。V6.1 整队任务是每名上场球员各受一次独立 ST4 Block 的固定压力组合，不是完整回合模拟、威胁频率或胜率。个人候选含部分引擎证据；阵容边际差仍是代理，因此球队榜属于阶段实验，不是正式实力榜。

Coach Skill · 教练水平情境

默认 Experienced=60；Beginner=25、Expert=90。六维雷达不变。逐项按同一球员“有技能/去掉该技能”做评分差分，按 Bloodboard V5 规则摘要里的执行依赖拆分 Passive Value 与 Skill-Expressive Value。R=1−(1−CoachSkill/100)×mean(Execution Dependency,Role Complexity,Synergy Complexity,Mistake Punishment)/100；Realized Axis=Base Axis−Skill-Expressive Value×(1−R)。球队按六轴权重合成实时 Strength，并在赛制内重新排 Tier；球员/明星详情也展示 Skill Floor（新手 Strength）、Skill Ceiling（高手 Strength）、执行复杂度和失误惩罚。球队的角色覆盖、协同关系与替补恢复会按名单和七/十一人制重算。当前是实验预览：技能执行依赖来自规则文本线索，角色复杂度、协同与失误惩罚仍需比赛/行为数据校准；不把预览榜当作官方实力结论。

明星适用性与阵容性价比

基础明星六维不随可选球队变化；明星阵容适配只按十一人制参考阵容评估，七人制因当前明星规则接入范围不足而不参与。令 Q(T)=0.22快攻+0.18控球+0.16杀伤+0.15生存+0.15控场+0.14适应力，ΔQⱼ=Q(Tⱼ+明星组合)−Q(Tⱼ)。主要适配价值为 U=Σ合法候选阵容ΔQⱼ÷当前筛选下全部候选阵容数，不可合法加入的阵容贡献记为0；因此它同时反映可用范围和加队后的增益大小。性价比排行为 100,000×U÷明星/组合总价。Dribl/Drull 等配对明星作为组合加入并按组合总价计算。正增益阵容率 count(ΔQⱼ>0)÷合法候选阵容数 仅在详情中辅助展示，不能单独作为适用性分数：只有一套阵容且增益很小，也会有100%的正增益率。详情显示每队全部六维增减、合法可用数与候选数。若加入后超过 16 人，模型只按当前球队总评的前五维权重（22/18/16/15/15）比较原球员并移出分数最低者，再重算阵容。明星增益的六维权重与球队总评一致。当前模型不虚构队友配合、特殊规则的条件收益、站位、阵容预算重配或教练策略；参考名单覆盖度不是联赛出场概率。因而它是阵容影响代理，不是胜率、金币收益保证，也不替代个人能力评分。

技能、明星规则与边界

属性、基础技能、特性及明星规则通过相应任务分支改变概率或显示条件增益；一次性、配对、团队和依赖站位的效果不会假设整场无限使用。尚无队友/棋盘/对手输入的效果只作条件展示，避免假装它们必定触发。规则公式依据第三季规则书与 FAQ；动态规则适用性、完整回合选择、天气、教练策略、团队资源频率与各阈值校准仍需后续完善。任何综合分都不等于购买价值或胜率。
